Twitter Daily plan

main · worktree /Users/anishthite/workspace/poaster · 2026-07-09 · status blocked · blast low

Summary

Goal
Scaffold a local daily personal X/Twitter learning digest app.
Source
pi-chrome against signed-in local Chrome X tabs.
Surface
cron/launchd, bin/run-daily.sh, public/index.html.
Schema
Local JSON files: raw, digests, state.json.
Mobile
Local static page; responsive CSS in implementation.
Open Qs
2 (Q-004, Q-005).

Algorithm

  1. Run local scheduler.
  2. Invoke pi -p with the fixed daily prompt.
  3. Use pi-chrome to read bounded X surfaces.
  4. Write data/raw/YYYY-MM-DD.json and data/digests/YYYY-MM-DD.json.
  5. Render public/index.html for local viewing.

UI layout

  1. Controls: open Chrome auth, run daily scrape, and refresh status.
  2. Header: latest digest day and source counts.
  3. Digest: markdown bullets for topics, lessons, and follow-up ideas.
  4. History: previous day links.

Decisions

IDChoice · Rationale
D-001Use twitter-daily/. Keeps the digest app separate from poaster-app/.
D-002Prefer official API/export. Cookie scraping is brittle and credential-risky.
D-003Use one Cloudflare Worker. Existing repo already deploys Workers.
D-004Use D1. Queryable history costs little.
D-005Serve HTML from the Worker. React is not needed for a one-page digest.
D-006Use local scheduler plus Pi. Supersedes D-003 because the app must use pi-chrome.
D-007Use JSON files. Supersedes D-004 because local single-user history does not need a database.
D-008Serve static local HTML. Supersedes D-005 because no Worker runs in v1.
D-009Use pi-chrome over API/export. Supersedes D-002 per user requirement.
D-010Wrap pi -p in scripts/run-pi.mjs. Prevents silent no-output hangs from becoming endless cron runs.
D-011Ignore generated data. Raw X data stays out of git.
D-012Add npm run auth. Makes the safe long-term authorization path one command.
D-013Add a local server. Lets the web app open authorization and run the job without browser-side shell access.
D-014Require an in-memory header token for control endpoints. Blocks cross-origin form posts from triggering local actions.
D-015Parse generated inline script in tests. Catches escaped newline bugs before the controls freeze.

Tradeoffs

IDPicked over Rejected · Reason
T-001D1 over KV. History queries need rows, not blobs.
T-002Stub digest before LLM. Ingestion should fail independently from summarization.
T-003Local files over D1. Plain files are enough for one daily local run.
T-004pi-chrome over X API. Signed-in browser access is the requested source.
T-005Static HTML over app framework. One digest page does not need React.
T-006Auth-launch button over bypassing pi-chrome. Keeps the explicit confirmation gate intact.
