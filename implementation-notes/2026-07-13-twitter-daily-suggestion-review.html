UI layout

  1. Render each latest suggestion as a review card.
  2. Place source tweet embed above the suggested reply/post.
  3. Save Approve/Deny plus the freeform reason through the local server.

Decisions

IDChoice · Rationale
D-001Save reviews as JSON files. Existing app is file-backed and needs no database.
D-002Upsert by suggestionFile#suggestionIndex. Re-reviewing a draft should replace stale notes.
D-003Use X native embeds. It is the smallest source-card loader and degrades to a link.

IDPicked over Rejected · Reason
