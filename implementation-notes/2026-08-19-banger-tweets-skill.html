Method

  1. Drive signed-in Chrome over pi-chrome HTTP bridge (POST 127.0.0.1:17318/command, actions tab.new/page.navigate/page.evaluate); session lacked chrome_* tools so used curl directly.
  2. Resolve handle via a[data-testid=AppTabBar_Profile_Link] → @anishthite.
  3. Scroll loop in bash: short page.evaluate per step appends article[data-testid=tweet] rows (text, time, link, [role=group] aria-label metrics, socialContext, Replying to flag) to window.__seen. Long single evaluates detach the debugger — keep each call <5s.
  4. Parse aria-label ("N replies, N reposts, N likes, N views, N bookmarks") with K/M suffixes; bucket by length/newlines/question/link/mention/caps; rank by likes.
