Decisions

IDChoice · Rationale
D-001Use three fixed workflows. The user named three jobs; a generic workflow builder is dead weight.
D-002Keep the current /api/run endpoint. One optional field avoids new route plumbing.
D-003Write context packs under data/context/. They are input for later LLM runs, not daily digests.
D-004Retry chrome_evaluate timeouts with smaller visible-article reads. X can stall CDP on heavy page evaluation.

Tradeoffs

IDPicked over Rejected · Reason
T-001Separate workflow buttons over one multi-step mega-run. Partial runs are easier to retry after Chrome flakes.
T-002One automatic retry over disabling background mode. The retry keeps Chrome from stealing focus.
