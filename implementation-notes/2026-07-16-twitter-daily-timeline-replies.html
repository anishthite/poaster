Summary

Goal
Make the default run scrape home timeline tweets and up to 3 visible replies per tweet.
Source
x.com/home via signed-in Chrome and background-safe chrome_evaluate.
Surface
twitter-daily/prompts/daily-twitter.md, scripts/server.mjs, scripts/cli.mjs, scripts/render.mjs.
Schema
Add nested items[].replies[] while keeping top-level tweet fields stable.
Open Qs
0.

Data contract

{
  id: string,
  url: string,
  author: string,
  handle: string,
  text: string,
  createdAt: string,
  metrics: { replies?: number, reposts?: number, likes?: number, views?: number },
  media: [{ kind: "image" | "video" | "gif", alt?: string, url?: string }],
  capturedAt: string,
  replies: [{
    id: string,
    url: string,
    author: string,
    handle: string,
    text: string,
    createdAt: string,
    metrics: { replies?: number, reposts?: number, likes?: number, views?: number },
    capturedAt: string
  }]
}

Algorithm

  1. Read visible home timeline article nodes; keep stable tweet URLs and visible text/metrics.
  2. Open each kept tweet URL; read the conversation page; store first 3 visible replies after the original.
  3. Scroll the home timeline with window.scrollBy; stop at 20 timeline tweets or 10 minutes.
  4. Write raw JSON with nested replies; distill from timeline tweets plus replies without inventing missing metrics.
