# Poaster reply guidance

- Reply only when the source tweet gives a real opening; don't force a take onto a weak prompt.
- Make the reply useful on its own: name the specific mechanism, tradeoff, or example the original tweet missed.
- Match the conversation's scope; add context without hijacking the thread into a new post.
- When someone asks a narrow question, answer it first in one short sentence; add context only if it clarifies the answer.
- In technical threads, ask for the missing comparison or mechanism, not a broad "thoughts?" prompt.
- Skip pure praise replies; attach a specific analogy, next-step request, or concrete observation.
